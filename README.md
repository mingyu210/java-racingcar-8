# java-racingcar-precourse
# 🚗 자동차 경주 게임 (Racing Car Game)

## 📘 프로젝트 개요
사용자가 입력한 자동차 이름들과 시도 횟수를 기반으로,  
각 자동차가 랜덤한 수(0~9)를 받아 이동 여부를 결정하고,  
가장 멀리 이동한 자동차를 최종 우승자로 출력하는 프로그램입니다.

---

## 🧩 구현 기능 목록

### 1. 입력 기능 (View / Controller)
- 사용자로부터 자동차 이름과 시도 횟수를 입력받는다.
- 자동차 이름은 쉼표(,)로 구분한다.
- 시도 횟수는 정수형으로 입력받는다.

### 2. 자동차 생성 기능 (Model)
- 입력받은 자동차 이름을 기반으로 `Car` 객체를 생성한다.
- 자동차 목록을 관리하는 배열(또는 리스트)을 생성한다.

### 3. 경주 진행 기능 (Controller)
- 시도 횟수 `T`번 반복한다.
- 각 자동차는 매번 0~9 사이의 무작위 값을 얻는다.
- 랜덤 값이 **4 이상일 때만 이동 거리 +한다**,  
  0~3일 때는 이동하지 않는다.
- 각 라운드마다 현재 상태를 출력한다.

### 4. 결과 출력 기능 (View)
- 모든 시도가 끝난 후,  
  가장 많이 이동한 자동차를 우승자로 출력한다.
- 공동 우승일 경우, 여러 자동차를 함께 출력한다(,를 이용하여 구분).

### 5. 예외 처리 기능
- 자동차 이름이 **빈 문자열이거나 공백만 있을 경우** 예외 발생.
- 자동차 이름의 길이가 **5자를 초과할 경우** 예외 발생.
- 자동차 이름이 중복될 경우 예외 발생.
- 시도 횟수가 **음수이거나 숫자가 아닐 경우** 예외 발생.

## 🧱 MVC 구조

| 계층 | 역할 | 구성 클래스 |
|------|------|-------------|
| **Model** | 자동차의 상태와 동작 정의 | `Car` |
| **View** | 사용자 입력 및 결과 출력 담당 | `InputView`, `ResultView` |
| **Controller** | 전체 게임의 흐름 제어 | `RacingGameController` |
